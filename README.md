# Услуги ИИ — Лендинг, Форма ТЗ и CRM на Yandex Cloud (РФ)

Проект объединяет публичный сайт услуг (`index.html`), подробную форму технического задания (`tz.html`) и CRM-панель (`crm.html`). Первичный сбор и хранение заявок и ТЗ переведены на серверы в РФ (**Yandex Cloud Functions + Managed Service for YDB**, регион `ru-central1`) в соответствии с ч. 5 ст. 18 152-ФЗ.

## Структура файлов

- `index.html` — основной сайт (услуги, интерактивные демо, калькулятор, мини-ТЗ, форма заявки с согласием 152-ФЗ, юридические документы).
- `tz.html` — отдельная подробная форма технического задания (ТЗ) в стиле сайта для заполнения клиентом (с динамическими блоками под сайт, приглашение, бота или другой проект).
- `crm.html` — защищённая CRM-доска с канбаном (drag-and-drop), вкладкой «Брифы и ТЗ» (редактор, архив, промпты для ИИ, выгрузка в `.doc`, `.md`, PDF), выгрузкой заявок в Excel (CSV) и поддержкой PWA.
- `config.js` — единый файл конфигурации, куда вставляется ссылка на вашу функцию Yandex Cloud.
- `yandex-cloud/index.py` и `yandex-cloud/requirements.txt` — код серверной функции на Python для Yandex Cloud Functions + YDB (автоматически создаёт таблицы `leads` и `briefs`, проверяет пароль администратора и шлёт уведомления в Telegram).
- `yandex-cloud/DEPLOY_YANDEX_CLOUD.md` — пошаговая инструкция по настройке Yandex Cloud в веб-консоли за ~10 минут.
- `manifest.json` и `icon.svg` — манифест и иконка для установки CRM на телефон или Mac как отдельного приложения (PWA).

---

## Быстрый старт

1. Разверните базу **YDB Serverless** и функцию **Cloud Functions** по инструкции в [yandex-cloud/DEPLOY_YANDEX_CLOUD.md](yandex-cloud/DEPLOY_YANDEX_CLOUD.md).
2. Вставьте полученный URL функции в [config.js](config.js).
3. Опубликуйте проект на хостинге (GitHub Pages или Object Storage в РФ).
4. Откройте `crm.html`, введите пароль администратора из переменных функции и пользуйтесь CRM (публичная ссылка на CRM из футера сайта убрана).
